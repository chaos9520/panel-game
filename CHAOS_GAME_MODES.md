# The Game Modes
There will be 5 game modes players can play on. The attributes listed below affect only the player that is playing on the selected mode.

Both players must select the same game mode for a match to be ranked, and ranked play is not allowed on the Insane game mode.
## __Classic Mode__
This is for players that like their long games. Here you go. :stuck_out_tongue:
- Margin time for queued garbage will be stretched across 10 minutes.
- Queued garbage falls one-by-one.
- Garbage margin will be 50 pieces versus the normal 30.
- Shake time will feel closer to the normal build compared to the other modes, but garbage that is completely on-screen will not shake again.
- Shake margin is more forgiving compared to the other modes.
## __Modern Mode__
The default game mode.
- Queued garbage falls all at once.
- Margin time for queued garbage is stretched across 5 minutes.
- Garbage margin is 30 pieces.
## __Competitive Mode__
This mode is similar to Modern, but with one difference: Starting health is set to 1 frame.
## __Hard Mode__
I'm definitely keeping this as it drastically changes gameplay dynamics in a good way. This mode is similar to Modern, but with one key difference: There will be no stop time for combos or chains.
## __Insane Mode__
Hard Mode doesn't challenge you enough? This may suit your taste. :stuck_out_tongue:
- There will be no stop time for combos or chains.
- Starting health is set to 1 frame.
- Queued garbage falls one-by-one... at first...
  - At 2 minutes, queued garbage will change to fall all at once.
- Shake margin will be far less forgiving.
- At 2 minutes, the player's +3s will send garbage if it is part of a chain. *(This will send 2x1s, and they will not count towards overall GPM.)*
